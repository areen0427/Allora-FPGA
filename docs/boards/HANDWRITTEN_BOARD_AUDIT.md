# Handwritten board resource audit

Audit date: 2026-10-16. This supplements [BOARD_DATA_AUDIT.md](BOARD_DATA_AUDIT.md) for the eleven handwritten definition files and their **39 existing concrete variants**. It covers 27 iCE40/ECP5 project targets and 12 pin-mapping-only targets. No target was promoted to a new synthesis, programming, or project capability.

Verification here means a fact was checked against published board-maintainer platform declarations, maker constraints, or a maker schematic. It does not mean that an assembled board was electrically measured or programmed. The workplan's connected-hardware release tests and programming-command work remain outstanding.

The provided `litex-boards-master` folder was compared read-only with the current upstream LiteX-Boards checkout at commit `27cc6fd9b6b2d7a4ddaeb83777eaa1be32d91b65`. Most differences for these platforms are extension-helper refactors; substantive changes include added Colorlight connectors and the corrected FK33 differential clock pair. The supplied [hdl/constraints](https://github.com/hdl/constraints) repository was checked at commit `cd6ebf23edb1209c98b7d88b7167a4707e5372ef`. Maker documentation takes precedence when those sources disagree.

`verifiedPlatformData.ts` records the selected declaration, immutable upstream URL, source hash, and extraction notes. `handwrittenResources.ts` adds the static resource and connector declarations while preserving existing meaningful signal aliases. Multiple names for the same LED/button pad count as one channel; GPIO alternate functions remain explicit aliases. Source TODO/unknown verification status is preserved. A `_n` suffix alone does not establish electrical polarity, and differential negative pins never imply active-low controls.

## Resolved conflicts and gaps

- **Arty A7-100T:** replaced an empty mapping with the maker's Rev D/E constraints. The same verified pin map applies to the 35T variant, including previously absent four user buttons, switches, PMODs, and peripheral contacts.
- **ECPIX-5:** filled the missing two RGB packages (12 channels total), verified active-low cathodes through non-inverting buffers, and added the 26 MHz N22 oscillator. The 100 MHz AF12/AF13 source is explicitly a dedicated SERDES reference, not a general-purpose system clock. The AUX VCXO footprint is marked not mounted and is not assigned a guessed frequency.
- **iCESugar Pro:** the maker's v1.3 schematic connects RGB cathodes to ground; FPGA anodes are active-high. This overrides misleading LiteX `user_led_n` names. The maker's LFE5U-25F BG256 identity agrees with the current catalog; the historical workplan's UM5G label is obsolete.
- **AC701:** hdl/constraints names UART directions from the bridge; app signal aliases now use FPGA direction. Its LVCMOS25 UART declaration conflicts with the vendor's 1.8 V bank. The maker's LVDS_25 system-clock standard also takes precedence over LiteX DIFF_SSTL15. The north button's `_N` means north, not inverted. The 156.25 MHz Si570 clock is its documented power-on value and may be reprogrammed externally.
- **TrellisBoard and NetV2:** corrected stale oscillator and named-resource pads against their actual platform definitions. A syntactically valid package pad was not considered sufficient evidence of the signal's function.
- **FK33:** live upstream corrected the old negative clock pad AY23 to BC27 and fixed the PCIe reference-clock P/N ordering. Its seven LED pads are now available.
- **Control counts:** Fomu contacts are touch GPIOs; DIP contacts are switches; Versa display segments are grouped as a peripheral; ULX3S OLED controls remain peripheral I/O. Multiple aliases do not inflate LED/button channel counts.

## Remaining limits

- Data is revision-specific. A shared family name does not establish compatibility with unlisted revisions, stuffing options, or third-party clones.
- Unknown electrical polarity stays unknown for newly imported contacts unless a schematic or explicit source statement establishes it. Existing hand-reviewed controls retain their documented behavior; no polarity was derived from differential `_n` labels.
- Connector aliases, memory buses, and peripheral pins can share pads. Listing both functions does not mean they may be used together. P2 UART on Acorn requires an external adapter; iCEBreaker snap-off contacts require the attached break-off or its PMOD connection.
- Dedicated reference clocks and NM oscillator footprints are not ordinary assignable clock inputs. TrellisBoard's broken Rev 1.0 100 MHz route is excluded from clock selection.
- Published metadata does not validate programming adapters, USB identifiers at runtime, bootloader entry, SRAM/flash commands, timing closure, or observed hardware operation. Those workplan items require connected-board tests.

Regression tests in `allora-fpga/tests/handwritten-board-data.test.mjs` anchor these corrections against independent maker facts. The app's general board-resource tests separately check propagation to diagrams and resource browsers.
