Explore the workspaces

Every tool.
The same project.

One dock brings the full workflow within reach. Explore each workspace below, or click a capture to see the details.

01 / Editor

Write RTL with room to focus.

A Monaco editor, shared project explorer, file tabs, and RTL hierarchy keep multi-file designs organized. Autosave keeps your source up to date as you move between tools.

02 / Testbench

Follow every signal.

Choose a testbench, run it with Icarus Verilog, and inspect the resulting VCD waveforms. An open waveform canvas sits alongside setup, files, and simulator logs.

03 / Synthesis

See the logic behind your RTL.

Run Yosys and review the design report. Open the Synthesis Explorer to navigate hierarchy, trace connections, inspect logic, and move back to the source.

04 / Pin Mapping

Connect the design to the board.

Assign RTL ports to physical resources in Simple or Advanced mode. Review assignments, board resources, validation, and generated constraints together.

05 / Bitstream

Build with the details in view.

Check build preflight and health, then run synthesis, placement, routing, and packing. Build Log, Health, and Bitstream Preview share one workspace. Review timing and build history in Health.

06 / Program

Meet the hardware.

Choose a generated bitstream and matching programmer, detect your board, and program it. The integrated Serial Monitor lets you inspect and send messages without leaving Program.

07 / Virtual FPGA

Try the hardware before you have it.

Compile real RTL with Verilator, map ports to virtual controls, and run, pause, step, or reset the design. Virtual FPGA is part of the same project dock.

Connected design tools

The Allora Link.

Three design tools that connect your RTL, peripherals, memory assets, and register maps. Use them alongside AI Design Studio and the core workspaces, from Home or the project dock.

01 / Connect your design

A visual workbench for your real RTL.

Arrange buttons, switches, LEDs, seven-segment displays, and a UART terminal. Connect each device to your RTL ports, then compile with Verilator to run, pause, and step through live behavior.

Devices, connections, and layout are saved with the project.

02 / Create memory assets

Turn images and data into FPGA memory.

Import images, binary files, or numeric tables. Preview monochrome, RGB565, indexed, integer, or fixed-point conversions, inspect the encoded words, and generate .hex files with an optional Verilog ROM.

Generated assets work with the editor, simulation, and physical builds.

03 / Define your interface

One register map for hardware and firmware.

Define registers, byte offsets, bit fields, resets, and access modes with a live bit layout and validation. Generate a SystemVerilog register bank, matching C header, JSON map, and wiring snippet.

Optional reviewed wrappers help connect the generated bank to your RTL.
